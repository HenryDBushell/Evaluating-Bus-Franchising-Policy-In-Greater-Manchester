# Evaluating-Bus-Franchising-Policy-In-Greater-Manchester
This is a paper written in the second year of my BSc Economics course for the module ESPS0015 Political Economy. It uses standard DiD methods (mainly TWFE DiD) to evaluate the efficacy of Mayor Burnham's bus franchising policy on the number of bus journeys taken in Greater Manchester. The analysis is then extended by using the synthetic control method to ask the same question, with a different resultant conclusion. The paper is more of an proof-of-concept, with sufficient data not yet being available to evaluate the policy properly. The main aim of the paper is to apply serious undergraduate-level econoemtrics to a novel research question, and the limits of the approach are discussed to a great extent in the appendix.
